# Demo video/gif masters

Original `final_*.gif` screen recordings were converted to `.mp4` + `.webm`
(live in `src/assets/images/projects/<project>/`) and rendered as `<video>`
on project pages. The `final_*.gif` files referenced by the content schema
in `src/assets/...` are 67-byte placeholders; these are the real masters if
re-encoding is ever needed.
